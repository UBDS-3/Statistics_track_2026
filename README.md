## For faculty members

### Render.sh script

The script `render.sh` can be used for batch processing multiple sources, it required `quarto-cli` binaries installed and a path to your `R_HOME` (see below). For usage run `./render.sh`.

#### Usage

```bash
./render.sh --type <type|all> [--lab <labs|all>]
```

* `--type`: one or more of `solved` `simplified` `default` `public` (or `all`)
* `--lab`: one or more of `testing` `exploratory` `clustering` `omics` `ML` `regression` `randomness` `multivariate` (or `all`); defaults to all labs if omitted

Examples:

```bash
./render.sh --type solved --lab multivariate     # one type, one lab
./render.sh --type solved simplified --lab ML regression
./render.sh --type all --lab all                 # render everything
./render.sh --type public --lab multivariate     # answers-hidden page, written to docs/
```

Rendered output is written next to each `.qmd` (e.g. `labs/multivariate/multivariate.solved.html`), except `public`, which is written to `docs/<lab>/index.html` (see "Published pages" below). The `exploratory` and `randomness` labs are always rendered as `default` only, and are skipped for `public` since they don't yet gate solutions behind a param.

#### Prerequisites

* **bash** 
* **quarto** — must be installed. If it is not found, install [quarto-cli](https://quarto.org/docs/get-started/) or add it to your `PATH`.
* **R packages** — each lab loads its own packages via `library()`; a missing one fails the render with `there is no package called '<pkg>'`. Install the reported package and re-run, e.g.:

  ```r
  install.packages(c("GGally", "ade4", "factoextra"))
  ```

Make sure to have proper `R_HOME` variable, for macOS with RStudio (latest) is `R_HOME=/Library/Frameworks/R.framework/Resources`

### Published pages

Student-facing pages (answers hidden) are published to
**https://ubds-3.github.io/Statistics_track_2026/**.

`docs/` is auto-generated by `.github/workflows/publish-docs.yml` on every
push to `main` that touches a `.qmd` file (or manually via the Actions tab →
"Publish docs" → Run workflow) — do not hand-edit it. A lab is included
automatically once its `.qmd` gates solution chunks behind
`params$include_answers` (see `labs/multivariate/multivariate.qmd` for the
pattern) — no script or workflow changes needed, `render.sh --type public`
detects it. Currently only the multivariate lab qualifies.
